# Globe coastline data

`land.json` derives from Natural Earth 1:110m land polygons:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Retrieved 2026-11-11. Rings retained; coordinates rounded to two decimals. 128 rings, 5,143 vertices.

Natural Earth is public domain: https://www.naturalearthdata.com/about/terms-of-use/
The static SVG fallback is generated from the same geometry, with an orthographic projection centered on Asia. Neither representation is suitable for navigation or precise location.

The approximate Nepal marker at 84°E, 28°N is a regional visual locator, not a claim about the owner's personal coordinates. Confirmed profile text is Bharatpur, Chitwan, Nepal. No geolocation API is used.
